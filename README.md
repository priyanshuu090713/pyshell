# pyshell
a complete sim shell 
## how to use
to use do the following in order:
use the given command's in the shell :
while staying in the directory
```shell
venv/script/activate
py main.py
```
a venv is provided , to stay updated use 
```shell
venv/script/active #dont write if venv is allready active
pip update
```
## info
this is written in python 3.15.0 , use this or versions ahead of this
