# pyshell
a complete sim shell
## how to use
to use do the following in order:
use the given command's in the shell :
while staying in the directory
```shell
venv/script/activate
py src/main.py # while staying in the main directory (pyshell folder)
```
a venv is provided , to stay updated on library updates ,use : 

```shell
venv/script/active #dont write if venv is allready active
pip update
```

to stay updated with versions and releases , do (if you have git) while staying in the main directory :
```shell
git pull
```
I recomend to do this time to time

## info
this is written in python 3.15.0 , use this or versions ahead of this
